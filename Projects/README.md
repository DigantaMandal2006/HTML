# HTML Projects Collection

A collection of seven beginner-friendly HTML projects created as part of my web development learning journey. Each project focuses on applying HTML elements to build structured web pages, with some inline CSS for presentation.

## Projects

| Project | Description | Key Concepts |
| --- | --- | --- |
| [CineWorld](./CineWorld/CineWorld.html) | A movie-streaming themed page featuring a hero section, movie genres, trending titles, subscription plans, and user testimonials. | Headings, links, images, tables, sections, inline styling |
| [Proform](./Proform/proform.html) | A professional multi-section portal containing account registration, login, application, and feedback forms. | Forms, inputs, labels, navigation, form controls |
| [Result](./Result/Result.html) | A university semester result statement displaying candidate details, subject-wise marks, and an overall performance summary. | HTML tables, table headings, text formatting |
| [Resume](./Resume/Resume.html) | A personal resume web page introducing my background, academic journey, projects, and contact links. | Headings, paragraphs, lists, links, images, text formatting |
| [Structural](./Structural/Structural.html) | An educational article-style website explaining semantic HTML and the roles of sections, articles, navigation, figures, and side content. | Semantic HTML, articles, navigation, sections, accessibility concepts |
| [TechNova](./TechNova/TechnNova.html) | A technology company landing page presenting company information, leadership, services, service packages, and a consultation link. | Lists, tables, links, page layout, inline styling |
| [TechVisionNews](./TechVisionNews/TechVisionNews.html) | A technology news article page about the impact of artificial intelligence on modern education. | Article-style content, headings, paragraphs, text emphasis |

## What I'm Practicing

- Building well-structured pages with HTML5.
- Using headings, paragraphs, lists, links, and images.
- Creating tables to organize information clearly.
- Designing forms with appropriate input elements.
- Understanding semantic HTML and content organization.
- Exploring basic inline CSS while learning page presentation.

## How to View the Projects

Open any project folder and launch its `.html` file in a web browser. You can also click a project name in the table above to view its source code on GitHub.
