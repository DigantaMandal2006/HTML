# HTML Learning Journey 🌐

A collection of my **HTML learning notes, hands-on exercises, and beginner projects**. This repository documents the concepts I have practiced while learning how to structure web pages, build forms, organize content, and create complete page layouts.

The goal is simple: **learn a concept, write the code, see the browser output, and apply it in a project.**

## 📂 Repository Overview

| Folder | What's inside |
| --- | --- |
| [Notes](./Notes/) | Beginner-friendly HTML study material and runnable code examples, with explanations and browser outputs. |
| [Projects](./Projects/) | Seven practical HTML projects that apply the concepts covered in the notes. |

## 📚 HTML Notes

The **[Notes folder](./Notes/)** contains:

- **HTML Complete Beginner Notes With Outputs (PDF)** — A structured beginner guide covering important HTML concepts, code examples, and illustrated browser outputs.
- **HTML Beginner Runnable Examples (ZIP)** — Example files you can extract and open in a browser to practice alongside the notes.

Topics include document structure, tags and attributes, text formatting, lists, links, images, tables, forms, semantic HTML, metadata, and introductory SEO-related tags.

> Start with the PDF to understand each concept, then experiment with the runnable examples.

## 🧠 Concepts Covered

- **HTML essentials:** `<!DOCTYPE html>`, `html`, `head`, `body`, tags, elements, and attributes
- **Text and content:** headings, paragraphs, emphasis, highlighting, quotations, and lists
- **Links and media:** navigation links, internal links, images, and image descriptions
- **Tables:** `table`, `tr`, `th`, `td`, `thead`, `tbody`, and related table elements
- **Forms:** `form`, `label`, `input`, `textarea`, `select`, `option`, `button`, and basic validation
- **Semantic structure:** `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`
- **Document metadata:** page titles, character encoding, viewport, and introductory metadata/SEO concepts
- **Basic presentation:** inline CSS used in several beginner examples

## ▶️ How to Explore

1. Open the [Notes](./Notes/) folder and read the PDF.
2. Download and extract the runnable examples ZIP, then open an `.html` file in a web browser.
3. Browse the [Projects](./Projects/) folder and open any project's `.html` file to explore its code.
4. Try changing the text, images, form fields, or layout and refresh the browser to see what happens.

**Requirements:** A web browser and any text editor (such as VS Code). No installation or backend is required to view the static HTML pages. Form submissions that require a server are for demonstration unless a backend is implemented.
